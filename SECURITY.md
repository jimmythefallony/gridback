# Security Policy

## Supported versions

Only the latest GridBack release gets security fixes.

## Reporting a problem

If you find a security problem, please don't open a public issue.

Instead, report it privately with GitHub's "Report a vulnerability" button
on the Security tab of this repository.

Please include what you found, the steps to reproduce it, and the GridBack
and macOS versions you used.

I'll reply as soon as I can. GridBack is a small hobby project, so please
allow a few days.
